Privacy Policy

Placeholder text written for a hackathon prototype. It has not been reviewed by a lawyer and must be before any real launch.

What we collect

Chat messages, optional intake answers (income, bills, spending, debts, savings and goals), and a summary if you import a holdings CSV. The document picker does not upload or analyze document contents. A portfolio URL is saved in this browser session as a reference only; it is not sent to the server or used to connect to a brokerage. We do not ask for a bank or brokerage password.

How it's stored

Your data is tied to an anonymous id stored in your browser. In this prototype it lives in server memory and a temporary file; it may disappear on server restart. "Start over" clears your answers and chat. The optional portfolio URL is stored only in browser session storage.

Who processes it

Your questions and numbers are sent to Anthropic's Claude API to generate options and mentor replies. Payments are handled by Stripe; we never see your card number. Hosting is provided by Render.

What we don't do

We don't sell your data or use it for advertising.

Contact

Questions: open an issue on the project's GitHub repository.
