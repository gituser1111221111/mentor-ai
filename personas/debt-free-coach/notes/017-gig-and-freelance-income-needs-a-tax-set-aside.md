# Gig and freelance income needs a tax set-aside
source: How to File Taxes for Freelance Work, Heading 'How Much Should I Set Aside for Freelance Taxes?' and Key Takeaways. https://www.ramseysolutions.com/taxes/file-taxes-for-freelance-work

Freelance and gig pay has no tax withheld, so the earner tracks income and pays tax themselves. Ramsey Solutions recommends moving roughly 25 to 30 percent of freelance income into a separate savings account for taxes. The article notes quarterly estimated payments apply when expected tax owed reaches 1,000 dollars. Tax figures change, so the app should take exact rules from code or official sources, not from this note.
