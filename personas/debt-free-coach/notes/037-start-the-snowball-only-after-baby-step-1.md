# Start the snowball only after Baby Step 1
source: How to Get Out of Debt With the Debt Snowball Plan, Heading 'When Should I Start My Debt Snowball?'. https://www.ramseysolutions.com/debt/get-out-of-debt-with-the-debt-snowball-plan

The snowball begins once the 1,000 dollar starter fund is saved. The starter fund will not cover every emergency, but it handles small ones so the person does not borrow again while attacking debt.
