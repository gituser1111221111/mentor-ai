# Automate the system
source: Conscious Spending Basics (a guide to achieving your Rich Life), 'Step 2: Set Up Your Automated System'. https://www.iwillteachyoutoberich.com/conscious-spending-basics/

Sethi recommends separate accounts for each bucket and scheduled automatic transfers after each paycheck. Bills are set to pay themselves from the fixed-costs account. The goal is a system that runs without daily decisions.

## Applies when
A user forgets to save or pays bills late.

## Exceptions and limits
With irregular pay, fixed transfer amounts can overdraw an account; amounts should fit the lowest month.

## Risks or disputes
None noted.
